# Catálogo de Productos con AWS y FLOCI

## Descripción

Sistema de catálogo de productos desarrollado utilizando servicios AWS simulados mediante FLOCI. La aplicación permite registrar productos, almacenar atributos dinámicos, gestionar imágenes y publicar productos mediante una arquitectura basada en microservicios y contenedores.

## Tecnologías Utilizadas

### Backend
- Node.js
- Express
- PostgreSQL
- AWS SDK

### Frontend
- React
- Vite
- Nginx

### Infraestructura
- Docker
- Docker Compose
- FLOCI
- ECR
- EKS

### Servicios AWS Simulados
- RDS (PostgreSQL)
- DynamoDB
- S3
- Lambda
- ECR
- EKS
